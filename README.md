## Featured Project

### [DealRadar](https://github.com/guruveer-singh/DealRadar) — Duty Free vs. Market Price Intelligence

A price-comparison web application that tracks Delhi Duty Free pricing against
Indian domestic market rates (Amazon, Nykaa, state liquor MRPs) across perfumes,
liquor, chocolates, cosmetics, accessories, and beverages.

- Automated collectors pulling live prices from the Delhi Duty Free API
- A **Deal Score algorithm (0–100)** that ranks products by real savings
- Responsive interface with instant search, category filters, and multi-mode sorting
- Daily automated price refreshes running on **GitHub Actions**

`JavaScript` · `Node.js` · `GitHub Actions` · `GraphQL`
